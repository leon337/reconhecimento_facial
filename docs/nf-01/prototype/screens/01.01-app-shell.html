Substrato reutilizável do AppShell

A página fornece apenas metadados e conteúdo. O bootstrap compartilhado materializa Sidebar, TopHeader e os comportamentos estruturais sem copiar o shell para cada tela.

Contrato materializado em I3

Esta referência preserva dados fictícios e demonstra a separação entre o conteúdo específico da página e o AppShell administrativo compartilhado. O item “Registrar ponto” continua sendo uma saída conceitual para uma jornada independente.

Conteúdo preservadoO mesmo elemento `main` da página é movido para o workspace; um segundo `main` não é criado.
Montagem idempotenteChamadas repetidas de `NF01AppShell.mount()` não devem duplicar Sidebar, TopHeader, skip link ou shell.
Desktop / intermediárioSidebar expandida/recolhível em desktop largo e compacta na faixa intermediária.
